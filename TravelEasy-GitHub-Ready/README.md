# TravelEasy - Retro Maximalist Transport Booking

A highly visual, retro-modern transport booking platform inspired by vintage Indian railway posters, old bus terminal signboards, and printed travel tickets. Designed with a strict "Retro Maximalist" aesthetic.

## Tech Stack

- **React** (Vite)
- **Tailwind CSS** (for dense, custom styling)
- **Framer Motion** (for smooth micro-animations)
- **Lucide React** (icons)
- **Local Storage** (for persistence, no backend required)

## Features

- **Retro Maximalist UI**: Dense layout, layered cards, stacked typography, and vibrant colors (Vintage Cyan, Faded Orange, Deep Red, Charcoal Black).
- **Authentication**: Fully functional client-side login and signup using localStorage.
- **Booking Flow**: Search, view, and confirm tickets with realistic simulated flows.
- **Ticket Ledger**: A beautifully designed history of booked tickets resembling printed transit stubs.
- **Support Center**: Tactical "Control Center" with functional forms and integrated contact details.
- **Responsive**: Adapts perfectly from mobile to large desktop displays while maintaining the dense poster-like layout.

## Installation

1. Clone the repository
2. Navigate to the project folder:
```bash
cd retro-booking
```
3. Install dependencies:
```bash
npm install
```

## How to Run Locally

To start the development server:
```bash
npm run dev
```
The app will run on `http://localhost:5173/` by default. Open this URL in your browser to view the application.

## Deployment Steps

This project is optimized and ready for deployment on platforms like Vercel, Netlify, or GitHub Pages.

### To build for production:
```bash
npm run build
```
This will generate optimized static assets in the `dist/` directory.

### Deploying to Vercel (Recommended):
1. Create a new project on [Vercel](https://vercel.com)
2. Import this GitHub repository
3. The framework preset should automatically detect `Vite`
4. Deploy!
